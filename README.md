## 编辑与预览

- 首页在 `site/index.html`，专题页面、样式和计算逻辑在 `site/guides/citric-acid/`。
- 在浏览器打开 `site/index.html` 即可预览，无需安装依赖或启动后端。
- 推送到 `main` 会自动将 `site/` 部署到 GitHub Pages。也可以在 Actions 中手动运行 **Deploy GitHub Pages**。

## 查看部署状态

仓库 Settings → Pages 的发布来源为 **GitHub Actions**。在 [Actions](https://github.com/ChengRui24/everyday-toolkit/actions/workflows/pages.yml) 中可查看每次部署的状态和日志。
