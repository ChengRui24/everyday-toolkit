# 生活工具箱

收录中文生活清单和三个可直接使用的工具：单位换算、商品单价和账单平分。

[打开生活工具箱](https://chengrui24.github.io/everyday-toolkit/)

## 编辑与预览

- 修改 `site/index.html` 可增补生活知识，`site/tools.js` 保存工具逻辑，`site/style.css` 保存样式。
- 在浏览器打开 `site/index.html` 即可预览，无需安装依赖或启动后端。
- 推送到 `main` 会自动将 `site/` 部署到 GitHub Pages。也可以在 Actions 中手动运行 **Deploy GitHub Pages**。
